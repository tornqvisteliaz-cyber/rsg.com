      Set-up

        Customers link Discord under My account. The website adds them to your server and gives licence holders the buyer role; it is taken away when a licence is revoked. Lock the buyer channels to that role in Discord: edit the channel, Permissions, @everyone: View Channel off, your buyer role: View Channel on.

        In Discord: User Settings, Advanced, Developer Mode on. Then right-click the server icon, Copy Server ID.
        Server Settings, Roles, make a role such as Verified buyer, right-click it, Copy Role ID. Keep the bot's own role above it.
        None ticked: any active licence gives the role.

        In Discord

        Adds /verify, /status, /version, /licence (a member's own keys, only they see it), /download, /profile, /support and /ticket (open a private ticket), /account, /store, /roadmap, /faq, /socials and /help. Your own commands (Server tools) are added too. Press it again after an update to get new commands. Check everyone again gives or takes the role for every linked member.

        People click it to open a private ticket thread — no command to type. Each ticket has a Close button for staff.
